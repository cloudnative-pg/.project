# Security Policy

## Reporting Security Issues

The CloudNativePG maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/cloudnative-pg/cloudnative-pg/security/advisories/new) form.

For more details, see the [CloudNativePG security policy](https://github.com/cloudnative-pg/cloudnative-pg/blob/main/SECURITY.md).
